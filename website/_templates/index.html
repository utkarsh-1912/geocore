{{ icon('sparkles') }}GeoAI

An assistant that calls the calculation — it doesn’t guess it

GeoAI is a local assistant built into GeoCore. A small language model reads your question and chooses a tool; Groundhog does the engineering arithmetic. If an input is missing, GeoAI should ask rather than invent it.

  • Runs on your CPU through llama.cpp, using open GGUF models from several families (Qwen, Gemma, Phi, Llama, Granite, SmolLM) — swap models freely, GeoAI is not tied to one.
  • Models are downloaded only when you choose one ({{ model_min_mb|mb }} to {{ model_max_mb|mb }}) and stored on your computer.
  • The model can only call whitelisted, schema-validated tools — never arbitrary code, shell or files.
  • A local full-text index lets GeoAI cite your own project notes, reports and standards instead of relying on the model's memory.
  • With no model installed, GeoAI falls back to simpler rule-based tool selection.
{{ icon('info') }}

GeoAI is under active development. Treat its answers as a starting point for engineering judgement, not a substitute for it.

  1. You ask a question

    “Calculate the bearing capacity for the current profile.”

  2. Local model plans on device

    Picks a tool and extracts arguments with units — or asks you for what is missing.

  3. Tool registry validates

    Arguments are checked against the tool’s schema before anything runs.

  4. Groundhog calculates deterministic

    The same function you would run from the form, with the same inputs.

  5. Grounded answer

    GeoAI explains the result and shows which tool and method produced it.
