Run calculations, manage soil profiles and export results.

- [Running calculations](/docs/geocore/using/calculations) — Find a calculator, enter inputs, read the results and export them.
- [Soil profiles and AGS data](/docs/geocore/using/soil-profiles) — Create groundhog SoilProfile objects and CPT tables from CSV or Excel files, and load AGS files.
- [Calculation catalogue](/docs/geocore/using/modules) — Every calculator available in GeoCore, with links to the underlying groundhog API reference.
- [Eurocode 7 partial factors](/docs/geocore/using/eurocode7) — Default EN 1997-1 partial factor sets and design-approach combinations used by GeoCore's Eurocode 7 calculator.
- [Indian Standard (BIS) calculations](/docs/geocore/using/indian-standards) — Theory, equations, clause references and inputs for GeoCore's IS 6403, IS 1498, IS 2131, IS 1892, IS 1904, IS 2950 and IS 2720 calculators.
- [Customising calculator forms](/docs/geocore/using/parameter-overrides) — Development-mode tool for adjusting field labels, descriptions, units and input patterns of calculator forms.
- [Local calculation engine API](/docs/geocore/using/local-api) — The HTTP endpoints the desktop app uses to talk to GeoCore's local calculation engine.
