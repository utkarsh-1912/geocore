    In-situ tests

    groundhog 0.16.0

    Package groundhog.siteinvestigation.insitutests in groundhog 0.16.0.

    • PCPT functions — API reference for groundhog.siteinvestigation.insitutests.pcpt_correlations: 34 functions, 0 classes.
      • pcpt_normalisations: Carried out the necessary normalisation and correction on PCPT data to allow calculation of derived parameters and soil type classification.
      • soilclass_robertson: Provides soil type classification according to the soil behaviour type index by Robertson and Wride.
      • ic_soilclass_robertson: Provides soil type classification according to the soil behaviour type index by Robertson and Wride.
      • behaviourindex_pcpt_robertsonwride: Calculates the soil behaviour index according to Robertson and Wride (1998).
      • gmax_sand_rixstokoe: Calculates the small-strain shear modulus for uncemented silica sand based on cone resistance and vertical effective stress.
      • gmax_clay_maynerix: Mayne and Rix (1993) determined a relationship between small-strain shear modulus and cone tip resistance by studying 481 data sets from 31 sites all over the world.
      • relativedensity_ncsand_baldi: Calculates the relative density for normally consolidated sand based on calibration chamber tests on silica sand.
      • relativedensity_ocsand_baldi: Calculates the relative density for overconsolidated sand based on calibration chamber tests on silica sand.
      • coneresistance_ocsand_baldi: Calculates the cone resistance for a given relative density for overconsolidated sand based on calibration chamber tests on silica sand.
      • relativedensity_sand_jamiolkowski: Jamiolkowksi et al formulated a correlation for the relative density of dry sand based on calibration chamber tests.
      • frictionangle_sand_kulhawymayne: Determines the friction angle for sand based on calibration chamber tests.
      • undrainedshearstrength_clay_radlunne: Calculates the undrained shear strength of clay from net cone tip resistance.
      • frictionangle_overburden_kleven: This function calculates the friction angle according to the chart proposed by Kleven (1986).
      • ocr_cpt_lunne: Calculates the overconsolidation ratio (OCR) for clay based on normalised CPT properties.
      • sensitivity_frictionratio_lunne: Calculates the sensitivity of clay from the friction ratio according to Rad and Lunne (1986).
      • unitweight_mayne: Estimates the total unit weight for sand, clay and silt from CPT measurements.
      • vs_ic_robertsoncabal: Calculates shear wave velocity based on a correlation with total cone resistance and soil behaviour type index.
      • k0_sand_mayne: Calculates the lateral coefficient of earth pressure at rest based on calibration chamber tests on clean sands.
      • gmax_cpt_puechen: Calculates the small-strain modulus based on CPT data.
      • behaviourindex_pcpt_nonnormalised: Calculates the non-normalised soil behaviour type index.
      • drainedsecantmodulus_sand_bellotti: Calculates the drained secant modulus for various types of sand for an average strain of 0.1 percent.
      • gmax_voidratio_maynerix: Calculates the small-strain shear modulus for clay based on the void ratio of the material.
      • vs_cpt_andrus: Calculates shear wave velocity from CPT measurements based on a relation calibrated on 229 measurements of which the majority are S-PCPT with some cross-hole tests and suspension logger measurements.
      • vs_cpt_hegazymayne: The correlation between shear wave velocity and CPT properties developed by Hegazy and Mayne was based on a global databased from 73 sites with different soil conditions including sands, clays, soil mixtures and mine ta…
      • vs_cpt_longdonohue: The authors propose a correlation between shear wave velocity and CPT properties based on high-quality CPT tests and Gmax obtained from S-PCPT, MASW, cross-hole and block sampling.
      • soiltype_vs_longodonohue: Determines the soil type based on measured shear wave velocity and normalised cone resistance.
      • vs_cptd50_karrayetal: This correlation between Vs and normalised cone tip resistance takes into account the influence of median grain size.
      • vs_cpt_wrideetal: Calculates shear wave velocity based on normalised cone tip resistance based on test data from the CANLEX project.
      • vs_cpt_tonniandsimonini: The authors propose a correlation between CPT properties and shear wave velocity for the Treporti site near Venice, Italy which consist mostly of silty sediments.
      • vs_cpt_mcgannetal: The authors develop a correlation between shear wave velocity and CPT properties based on Christchurch-specific general soils.
      • constrainedmodulus_pcpt_robertson: Calculates the one-dimensional constrained modulus.
      • vs_stressdependent_stuyts: Calculates the shear wave velocity using the calibrated power-law expression proposed by Stuyts et al (2024).
      • dissipation_test_teh: Calculates the pore pressure dissipation from a dissipation tests in clay according to the normalised dissipation curves proposed by Teh & Houlsby (1991).
      • clippingdepths_qc1N_tianlehane: Calculates the depths where the normalised cone resistance reaches steady values in weak over strong layer systems based on the equations proposed by Tian and Lehane (2025).
    • pcpt_processing — API reference for groundhog.siteinvestigation.insitutests.pcpt_processing: 2 functions, 2 classes.
      • InsituTestProcessing: Abstract base class for the processing of in-situ tests.
      • PCPTProcessing: The PCPTProcessing class implements methods for reading, processing and presentation of PCPT data.
      • plot_longitudinal_profile: Creates a longitudinal profile along selected CPTs.
      • plot_combined_longitudinal_profile: Creates a longitudinal profile along selected CPTs and SoilProfile objects.
    • read_site_data — API reference for groundhog.siteinvestigation.insitutests.read_site_data: 1 functions, 0 classes.
      • read_ags: Reads AGS data from a file and extracts the data for a given groupname into a DataFrame.
    • SPT corrections and correlations — API reference for groundhog.siteinvestigation.insitutests.spt_correlations: 10 functions, 0 classes.
      • overburdencorrection_spt_liaowhitman: Applies a correction to the SPT N value to account for the effect of effective overburden pressure in granular soils.
      • spt_N60_correction: The performance of the SPT in a given soil type depends on the efficiency of energy transmission to the soil.
      • relativedensity_spt_kulhawymayne: Estimates relative density from SPT test.
      • undrainedshearstrength_spt_salgado: Calculates undrained shear strength based on plasticity index and SPT number (corrected to 60% energy ratio).
      • frictionangle_spt_kulhawymayne: Kulhawy and Mayne approximated the chart for friction angle selection from SPT using the formula given below.
      • relativedensityclass_spt_terzaghipeck: Defines the relative density class for SPT measurements in cohesionless soils based on the uncorrected N-number
      • overburdencorrection_spt_ISO: Corrects the SPT N number or corrected N number (N_{60}) for the effect of overburden pressure in granular soils.
      • frictionangle_spt_PHT: Correlation proposed by Peck, Hanson and Thornburn (1974) and mentioned by Wolff (1989)
      • youngsmodulus_spt_AASHTO: Calculates the Young's modulus based on corrected SPT number for various soil types.
      • undrainedshearstrengthclass_spt_terzaghipeck: Defines the relative density class for SPT measurements in cohesionless soils based on the uncorrected N-number
    • spt_processing — API reference for groundhog.siteinvestigation.insitutests.spt_processing: 0 functions, 1 classes.
