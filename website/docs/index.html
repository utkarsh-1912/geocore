GeoCore Documentation & Engineering Reference

Welcome to the technical reference manual for GeoCore — an open-source geotechnical desktop platform combining Python numerical engines with Electron and React. No sign-in or login required.

🚀 Offline-First Engine

Purely local execution on 127.0.0.1:8000. Subsurface project data stays private on your workstation.

📊 100+ Geotechnical Solvers

PCPT Robertson SBT, LCPC pile capacity, Vesic footing limits, Schmertmann settlement, and AGS 4.0 data exchange.

⏱️ Quickstart Guide

Launch GeoCore, load soil stratigraphy, and run a complete Robertson CPT sounding interpretation in less than 5 minutes:

1. Initialize a SoilProfile

Navigate to Site Investigation → Soil Profile and paste depth stratigraphy with Depth from [m], Depth to [m], and cone resistance qc [MPa].

2. Run PCPT Processing

Select the profile, configure groundwater depth ($z_w = 1.5\text{ m}$) and cone factor ($N_{kt} = 14.0$), then execute to generate multi-panel Robertson SBT curves.

3. Compute Bearing Capacity Envelope

Navigate to Shallow Foundations, supply footing geometry $B \times L$, strength parameters $\phi'$ and $c'$, and compute the 2D/3D interaction envelope.

🏗️ Deep Foundations & Pile Capacity

GeoCore implements industry-standard analytical formulations for axial pile resistance:

1. LCPC Method (Bustamante & Gianeselli / NF P 94-262)

Calculates unit base resistance $q_b$ and shaft friction $q_s$ from CPT cone resistance $q_c$:

$$R_b = A_b \cdot q_b = A_b \cdot k_b \cdot q_{ce}$$ $$R_s = \sum_{i=1}^n \pi D \cdot \frac{q_{ci}}{\beta} \cdot \Delta z_i$$

2. Koppejan Method (Dutch Standard NEN 6743)

$$q_b = \frac{1}{2} \cdot \alpha_p \cdot \beta \cdot s \cdot \left[ \frac{q_{c;I;mean} + q_{c;II;mean}}{2} + q_{c;III;mean} \right]$$

📐 Shallow Foundations & Settlement

Evaluate ultimate bearing capacity and elastic/consolidation settlement for eccentric and inclined loads:

Vesic / Eurocode 7 Bearing Capacity Equation

$$q_{ult} = c' N_c s_c d_c i_c + q' N_q s_q d_q i_q + \frac{1}{2} \gamma B' N_\gamma s_\gamma d_\gamma i_\gamma$$

API RP 2GEO Circular Effective Footing Area

$$A' = 2 \left[ R^2 \arccos\left(\frac{e}{R}\right) - e \sqrt{R^2 - e^2} \right]$$

🧪 Site Investigation & CPT Processing

Automated normalizations according to Robertson (1990/2009/2016) and Lunne et al. (1997):

$$q_t = q_c + u_2 \cdot (1 - a)$$ $$Q_{tn} = \left( \frac{q_t - \sigma_{v0}}{p_a} \right) \left( \frac{p_a}{\sigma'_{v0}} \right)^n$$ $$I_c = \left[ (3.47 - \log_{10} Q_{tn})^2 + (\log_{10} F_r + 1.22)^2 \right]^{0.5}$$ $$s_u = \frac{q_t - \sigma_{v0}}{N_{kt}}$$

📁 AGS 4.0 File Converter

Parse standard Association of Geotechnical Specialists (AGS 4.0) data files:

# Extract AGS group into a DataFrame
from core.wrappers import AGSConverter

conv = AGSConverter("ground_investigation.ags")
conv.extract_groupnames()
df_ispt = conv.convert_ags_group("ISPT")
print(df_ispt.head())

🏛️ System Architecture & Netlify Deployment

GeoCore utilizes a multi-tier local architecture:

  • Frontend: React 18 + Tailwind CSS + Lucide Icons + Plotly.js inside Electron.
  • Backend Kernel: Local FastAPI server running Python 3.11 with NumPy, SciPy, Groundhog, and Pandas.
  • Static Portal: Pure HTML5, Tailwind CSS, MathJax 3 with zero Python/MkDocs runtime dependencies on Netlify!
⚡ Netlify Zero-Config Deployment: Push this repository to GitHub and connect it to Netlify. The website/ folder is published statically in 2 seconds with zero build failures!
