GeoCore Geotechnical Workstation

GeoCore is a professional offline geotechnical engineering workstation designed for geotechnical engineers, offshore specialists, and consulting firms. It pairs an embedded local FastAPI computational backend with a modern React 19 / Tailwind / Electron interface.

100% Offline by Design: All 213+ calculations, SoilProfile interpretations, and Plotly graphics run strictly on your local CPU. No proprietary borehole data leaves your machine.

Core Workstation Capabilities

  • Analytical & Empirical Engine: Direct execution of 213+ validated routines from the Groundhog library.
  • Stratigraphy Object Model: Native SoilProfile management with layer boundaries, USCS soil types, CPT/SPT values, and groundwater tables.
  • Standards Compliance: Eurocode 7 (EN 1997-1), API RP 2A (21st & 22nd Edition), ASTM, DNV-RP-C212, and ISO 19901-4 standards.
  • Deliverable Generators: Export calculation sheets to PDF reports, Excel workbooks (.xlsx), CSV tables, and interactive Plotly HTML.

System Architecture

GeoCore follows a modular, decoupled desktop architecture: 

┌────────────────────────────────────────────────────────────┐
│              Electron Desktop Shell (Node.js)              │
├────────────────────────────┬───────────────────────────────┤
│    React 19 Frontend UI    │    Python FastAPI Backend     │
│   - SchemaForm Engine      │   - Groundhog Core Engine     │
│   - Plotly CAD Visualizer  │   - Pydantic v2 Validation    │
│   - SoilProfile Studio     │   - NumPy / SciPy Solvers     │

The frontend communicates with the local engine over HTTP loopback (127.0.0.1:8000). Calculations evaluate synchronously with sub-millisecond execution times.

SoilProfile Stratigraphy Model

The SoilProfile object represents a continuous vertical geological borehole. It contains stratigraphic layer intervals, strength parameters, unit weights, and water table elevations.

Defining a SoilProfile

A SoilProfile is represented as a structured table with core geotechnical layer parameters:

Column Key Unit Physical Parameter Description
Depth from m Top of stratum Layer upper boundary below ground level
Depth to m Bottom of stratum Layer lower boundary below ground level
SoilType - Classification Sand, Clay, Silt, Gravel, Peat
UnitWeight kN/m³ Bulk unit weight γ Total unit weight of the soil layer
FrictionAngle deg Effective φ' Drained internal friction angle
UndrainedCohesion kPa Undrained strength c_u Total strength for cohesive clay strata

Shallow Foundations Module

Calculates ultimate and allowable bearing capacity under vertical, inclined, and eccentric loading according to classic theories and Eurocode 7.

Formulations Implemented:

  • Terzaghi (1943): General bearing capacity equation with strip, round, and square shape factors.
  • Meyerhof (1963): Inclination factors and depth coefficients for shallow footings.
  • Hansen (1970) & Vesic (1973): Complete shape, depth, load inclination, ground slope, and base tilt factors.
  • Eurocode 7 EN 1997-1 Annex D: Partial factor verification across Design Approaches DA1, DA2, and DA3.
# Sample Python API Execution
import requests

payload = {
    "module_id": "shallowfoundations",
    "function_id": "calculate_bearing_capacity_meyerhof",
    "args": {
        "phi_eff": 34.0,
        "cohesion": 0.0,
        "gamma": 19.5,
        "width": 2.5,
        "length": 3.0,
        "depth": 1.5
    }
}
response = requests.post("http://127.0.0.1:8000/api/execute", json=payload)
print(response.json()["results"])
# Output: {"q_ult": 842.65, "q_net": 813.4, "N_q": 29.44, "N_gamma": 31.15}

Deep Foundations (Piles & Monopiles)

Axial pile capacity calculations (shaft friction \(q_s\) and end bearing \(q_b\)) in cohesive and cohesionless soils according to API RP 2A, ISO 19901-4, and offshore CPT methods (ICP-05, UWA-05).

API RP 2A Sand Method:

Unit skin friction is computed as \(f = eta \cdot \sigma'_v \le f_{lim}\) where \(eta = K \cdot an(\delta)\). Unit end bearing is evaluated as \(q = N_q \cdot \sigma'_v \le q_{lim}\).

Lateral Load Analysis: GeoCore includes Matlock (1970) soft clay p-y curves, Reese et al. (1975) stiff clay curves, and API (2000) sand p-y formulations for beam-on-elastic-foundation modeling.

Site Investigation & CPT Processing

Automated processing of piezocone penetrometer (CPTu) raw measurements (\(q_c, f_s, u_2\)):

  • Robertson (1990/2009) SBT: Normalised cone resistance \(Q_t\), friction ratio \(F_r\), and Soil Behavior Type Index \(I_c\).
  • Undrained Strength \(c_u\): Evaluated via \(c_u = (q_t - \sigma_{v0}) / N_{kt}\) with customizable empirical cone factor \(N_{kt}\).
  • SPT Corrections: Energy ratio correction to \(N_{60}\) and overburden stress normalization to \((N_1)_{60}\).

Eurocode 7 (EN 1997-1) Verification

GeoCore natively applies partial safety factors on actions, material properties (\(M1, M2\)), and resistances (\(R1, R2, R3, R4\)):

Design Approach Actions (A) Materials (M) Resistance (R)
DA1 - Comb. 1 A1 (γ_G=1.35) M1 (γ_φ=1.0) R1 (γ_R=1.0)
DA1 - Comb. 2 A2 (γ_G=1.0) M2 (γ_φ=1.25) R1 (γ_R=1.0)
DA2 A1 (γ_G=1.35) M1 (γ_φ=1.0) R2 (γ_R=1.4)
DA3 A1 / A2 M2 (γ_φ=1.25) R3 (γ_R=1.0)

Parameter Overrides & Customization

GeoCore allows engineers to adapt parameter symbols, default values, and display units without modifying the core codebase:

  1. Open any calculation module in development mode.
  2. Click the Edit Mode toggle in the parameter card header.
  3. Click any field to customize its display label, description, default value, and validation bounds.
  4. Click Save Override. Changes are persisted to the local schema_overrides.json store.
