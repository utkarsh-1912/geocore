System requirements

Operating systemWindows 10 or 11, 64-bit (x64)
macOS 12 Monterey or later
Processorx64 on Windows; Apple silicon (arm64) or Intel (x64) on macOS. GeoAI runs on the CPU — no GPU is needed.
Memory8 GB RAM recommended. With GeoAI, plan for the model’s size plus about 1–2 GB: 8 GB suits the Qwen 2.5 (1.5B Instruct), Qwen 2.5 (3B Instruct), Gemma 2 (2.6B IT) models; 16 GB is advisable for the larger ones.
Disk spaceAt least 1 GB free for the app, plus 986 MB–5.3 GB for each GeoAI model you download.
InternetNot required to run. Used only for update checks and optional model downloads — see Privacy.

Memory figures are guidance based on model file sizes, not measured benchmarks.

Intel Macs: release builds are produced on Apple silicon build machines, and the bundled Python calculation engine is compiled for the build machine’s processor. The Intel (x64) macOS package may therefore start without a working calculation engine. If you try it on an Intel Mac, please report how it goes.

Install on Windows

  1. Download GeoCore-Setup-<version>.exe and run it.
  2. SmartScreen: the installer is not code-signed yet, so Windows may show “Windows protected your PC”. Choose More info → Run anyway.
  3. The installer is per-user and does not need administrator rights. You can change the install folder; it creates Start-menu and desktop shortcuts.

Install on macOS

  1. Download the .dmg for your Mac (-arm64 for Apple silicon), open it and drag GeoCore to Applications.
  2. Gatekeeper: builds are ad-hoc signed but not notarised by Apple, so the first launch is blocked. Open System Settings → Privacy & Security and choose Open Anyway for GeoCore.
  3. If macOS reports that the app “is damaged”, the download quarantine flag is the cause. If you trust the download, clear it with: 
    xattr -dr com.apple.quarantine /Applications/GeoCore.app

First run

  • GeoCore starts its calculation engine in the background when it opens; the first launch can take a little longer than later ones.
  • Updates: installed builds check GitHub for a new version about 15 seconds after launch. On Windows, updates download in the background and install when you quit. On macOS, automatic updates need a signed build, so install new versions from this page.
  • Nothing else needs to be online. Without a network connection the update check simply fails and GeoCore works as normal.

GeoAI models

GeoAI needs a local language model in GGUF format. Models are not included in the installer; you choose one inside GeoCore:

  1. Open GeoAI in GeoCore and open its model list.
  2. Pick a model. GeoCore downloads it from Hugging Face into your models folder and makes it the active model.
  3. Already have a .gguf file? Select it by path instead, or copy it into the models folder: %APPDATA%\GeoCore\models on Windows, ~/.geocore/models on macOS.

All models are 4-bit (Q4_K_M) quantisations. Each model is published under its creator’s licence. Model choice for GeoAI is still being benchmarked; the smallest model is the quickest place to start.

Run from source

On Linux, or to develop GeoCore, run it from source with Node.js 18+ and Python 3.10+. The README has step-by-step instructions.
