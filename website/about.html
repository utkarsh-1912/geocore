About

Engineering software that shows its working

GeoCore is an open-source desktop application for geotechnical engineers. It is written and maintained by Utkarsh Gupta, and it stands on Groundhog — the open-source geotechnical library by Bruno Stuyts.

Mission

Geotechnical calculations are often scattered across spreadsheets, scripts and closed tools that are hard to audit. GeoCore brings a large, documented library of methods into one desktop application, and keeps three promises while doing it:

Offline
Your project data stays on your computer. The application works without an internet connection; the few optional network features are listed on the privacy page.
Deterministic
Numbers come from Groundhog functions with explicit inputs and units. The AI assistant does not do engineering arithmetic itself.
Grounded
A result should be traceable to a method, its inputs and, where possible, a published reference. When information is missing, the right answer is to ask, not to assume.

GeoCore is a tool to support engineering judgement. It does not certify a design as safe, and results should be checked by a qualified engineer.

How it is built

GeoCore is two programs packaged as one desktop app:

  • The interface — an Electron shell running a React application built with Vite. Charts use Plotly.js; reports use jsPDF; spreadsheets are read with Papa Parse and SheetJS.
  • The engine — a Python service built with FastAPI and bundled with PyInstaller. It listens only on your own machine (127.0.0.1:8000), discovers Groundhog’s functions and builds validated input forms for them. NumPy, SciPy and pandas do the numerical work underneath.
  • GeoAI — an optional assistant inside the engine. A small language model runs locally through llama-cpp-python (llama.cpp), selects a tool from a whitelisted, schema-validated registry, and passes the call to Groundhog. The model is swappable behind a provider interface rather than tied to one vendor.

Releases are built by GitHub Actions for Windows, macOS and Linux and published on GitHub Releases.

Credits

Groundhog by Bruno Stuyts performs every geotechnical calculation in GeoCore. It is a general-purpose, extensively documented Python package for onshore and offshore geotechnical engineering, released under the GNU GPLv3. GeoCore bundles Groundhog 0.15.0.

Source on GitHub · Documentation · PyPI

The methods implemented in Groundhog are the work of the researchers credited in its documentation and function docstrings. When you rely on a result, cite the original method as well as the software.

GeoCore also builds on these open-source projects, each under its own licence:

  • Electron, React, Vite, Tailwind CSS, Plotly.js, jsPDF, Papa Parse, SheetJS, Lucide icons, electron-updater
  • FastAPI, Uvicorn, Pydantic, NumPy, SciPy, pandas, Matplotlib, pyproj
  • llama.cpp and llama-cpp-python, and the Hugging Face Hub client for model downloads

GeoAI’s optional models are published by their creators — the Qwen team (Qwen 2.5) and Google (Gemma 2) — under their own licences, which apply when you download and use them.
