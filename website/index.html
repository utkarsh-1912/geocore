GeoAI

An assistant that calls the calculation. It doesn’t guess it.

A small language model on your computer picks the tool and fills in the inputs. Groundhog does the engineering arithmetic.

  • Runs locally with llama.cpp; models are optional downloads.
  • Can only call validated tools, never arbitrary code or files.
  • Asks when an input is missing instead of inventing it.

Under active development. Treat answers as a starting point for engineering judgement.
