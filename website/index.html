Download GeoCore

Open source · GPLv3 · Windows & macOS

Geotechnical calculations you can check, on your own machine.

GeoCore is a desktop workstation for geotechnical engineers. It puts 220 functions from the open-source Groundhog library behind validated forms, interactive plots and PDF reports — with GeoAI, an optional assistant that runs locally and hands every number to Groundhog.

Principles

Offline by default

Calculations, plots, reports and GeoAI run on your computer. Nothing about your project is uploaded. See every network call.

Deterministic results

Every number comes from a Groundhog function with explicit inputs and units — the same inputs always give the same answer.

Open and inspectable

GeoCore and Groundhog are both GPLv3. You can read the method behind any result, down to the source code.

Workflow

From input to report without leaving the app

Validated input forms

Parameters come with units, defaults and range checks. Invalid values are caught before a calculation runs, and labels can be adjusted with schema overrides.

Soil profiles as reusable objects

Build a SoilProfile once — by hand or from a spreadsheet — and reuse it across calculations that need layered input.

Interactive plots

Results render as interactive Plotly charts, drawn from a copy of Plotly bundled with the app.

Reports and exports

Export a PDF report with inputs, results and the captured chart, or save results as CSV or JSON.

History and favourites

Recent calculations are kept locally so you can recall inputs (Ctrl H), and favourite modules stay one click away.

Command palette

Jump to any calculation from the keyboard with Ctrl K (⌘ K on macOS).

GeoAI

An assistant that calls the calculation — it doesn’t guess it

GeoAI is a local assistant built into GeoCore. A small language model reads your question and chooses a tool; Groundhog does the engineering arithmetic. If an input is missing, GeoAI should ask rather than invent it.

  • Runs on your CPU through llama.cpp, using open GGUF models (Qwen and Gemma families).
  • Models are downloaded only when you choose one (1.0 GB to 5.3 GB) and stored on your computer.
  • The model can only call whitelisted, schema-validated tools — never arbitrary code, shell or files.
  • With no model installed, GeoAI falls back to simpler rule-based tool selection.

GeoAI is under active development. Treat its answers as a starting point for engineering judgement, not a substitute for it.

  1. You ask a question

    “Calculate the bearing capacity for the current profile.”

  2. Local model plans on device

    Picks a tool and extracts arguments with units — or asks you for what is missing.

  3. Tool registry validates

    Arguments are checked against the tool’s schema before anything runs.

  4. Groundhog calculates deterministic

    The same function you would run from the form, with the same inputs.

  5. Grounded answer

    GeoAI explains the result and shows which tool and method produced it.
