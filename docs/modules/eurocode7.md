# Eurocode 7 Standards & Factor Calculations

GeoCore provides automated statistical parameter selection and partial factor application based on Eurocode 7 (EN 1997-1).

## 1. Parameter Selection

### Constant Value Profile
Selects characteristic values assuming a constant soil property within a layer:
- **Low**: 5% fractile (conservative estimate).
- **Mean**: 95% confidence mean estimate.

### Linear Trend Analysis
Evaluates characteristic values where soil properties vary linearly with depth.
